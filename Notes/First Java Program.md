
#### **Create the Source File**

> Create a new file named `Main.java` in any text editor or IDE
> (such as IntelliJ IDEA, VS Code, or Eclipse).

```java
 public class Main {
     public static void main(String[] args) {
         System.out.println("Hello, World!");
     }
 }
 ```

#### **Compile the Code**

> Open your terminal, navigate to the directory where you saved
> `Main.java`, and compile the file using the Java compiler.

```bash
 javac Main.java
 ```

> This produces a compiled bytecode file named `Main.class`.

#### **Run the Application**

> Execute the compiled class file using the Java Virtual Machine (`java`).

```bash
 java Main
 ```

> **Note:** Do not include the **`.class`** extension when running this command.
